# Qubetics Validator Application

## What is Validator Application

```
validator application refers to software or a node running on a blockchain network that is responsible for verifying and validating transactions and blocks. Validators play a crucial role in maintaining the security and integrity of the blockchain
```

## Setting Up Environment Variables

```
This project requires environment variables to be configured for proper functionality. An example file (env.example) is provided to help you set up your environment.
```

## Install dependencies

```
npm install
```

## How to run your Application

```
npm run start
```

## How to build your Application

```
npm run build
```
